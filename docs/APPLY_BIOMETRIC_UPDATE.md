# تطبيق تحديث البصمة على TolanWorkforce

التاريخ: 2026-08-09

## قبل التطبيق

1. احتفظ بنسخة من المشروع الحالي وقاعدة البيانات.
2. لا تحذف ملف `.env` الحالي؛ تحديث البصمة لا يحتاج سرًا جديدًا في هذه المرحلة.
3. لا تغير منطق الحضور أو الرواتب يدويًا؛ التحديث يربط البصمة بالمحرك الحالي.

## طريقة التطبيق

إذا استخدمت حزمة **التحديث فقط**، فكها فوق جذر المشروع مع السماح باستبدال الملفات الموجودة. الحزمة تحافظ على نفس بنية المجلدات.

إذا استخدمت **النسخة الكاملة المنقحة**، انسخ إليها ملف `.env` وملفات الخطوط من مشروعك الأصلي عند الحاجة؛ تم استبعادهما من الحزمة المنقحة لأسباب أمنية/ترخيصية.

## تشغيل المشروع

بعد تثبيت الحزم المعتاد للمشروع وتشغيل الخادم، سيحاول Startup إنشاء الجداول البيومترية تلقائيًا بواسطة `CREATE TABLE IF NOT EXISTS`.

يوجد أيضًا SQL صريح عند الحاجة:

`drizzle/migrations/20260809_add_biometric_integration.sql`

انتظر ظهور السطر:

`[Migration] Biometric integration tables are ready`

## إعداد اختبار بدون جهاز

1. سجل الدخول بحساب `super_admin`.
2. افتح **إعدادات النظام → أجهزة البصمة**.
3. أضف جهازًا بالـSerial:
   `MB2000-TEST-001`
4. اربط رقم مستخدم الجهاز `60001` بعامل فعلي.
5. اضغط **قبول الحركات من الآن**.
6. شغل:

```bash
npm run biometric:simulate
```

لإرسال خروج بدل دخول:

```bash
BIOMETRIC_STATUS=1 npm run biometric:simulate
```

ولضبط وقت محدد:

```bash
BIOMETRIC_PUNCH_TIME="2026-08-09 08:00:00" npm run biometric:simulate
```

راقب تبويب **السجل الخام** ثم سجل الحضور الحالي.

## عند وصول MB2000 الحقيقي

لا تعدّل الرواتب أو الحضور. المطلوب أولًا هو اختبار الاتصال فقط:

1. اقرأ Serial Number الحقيقي.
2. سجله في صفحة أجهزة البصمة.
3. اربط عاملًا تجريبيًا واحدًا.
4. في ADMS أدخل عنوان السيرفر والمنفذ.
5. نفذ دخولًا وخروجًا تجريبيين.
6. أرسل لنا/راجع سجل `biometric_raw_events` لمعرفة شكل ATTLOG الفعلي وقيم status/verify الخاصة بالـFirmware.
7. بعد التأكد من البروتوكول، نثبت ملف التوافق النهائي ثم نعمم الربط على بقية العمال.

## ما الذي لا يجب فعله الآن؟

- لا ترفع قوالب البصمة/الوجه إلى التطبيق.
- لا تفترض أن كل Firmware يستخدم أكواد الحالة الإضافية نفسها.
- لا تفتح مسار ADMS عبر HTTP للإنترنت العام بلا حماية شبكة مناسبة.
- لا تربط جميع العمال قبل نجاح اختبار عامل واحد دخول/خروج وإعادة إرسال بعد انقطاع الإنترنت.
