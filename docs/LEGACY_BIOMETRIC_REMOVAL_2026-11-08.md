# إزالة نظام البصمة القديم — 2026-11-08

أزيل الكود الخاص بنظام البصمة القديم المدمج بناءً على طلب صاحب المشروع. أبقي نظام `biometric-service/` المستقل وربطه الحالي دون تعديل. هذا تغيير محلي؛ لم ينفذ نشر أو اختبار على جهاز حقيقي أو قاعدة الإنتاج.

## نطاق الإزالة

أزيلت الملفات التالية بعد فحص المراجع التنفيذية:

```text
server/biometric/zkteco-adms-routes.ts
server/biometric/zkteco-adms-service.ts
server/biometric/zkteco-push-parser.ts
server/biometric/biometric-attendance-rules.ts

scripts/simulate-zkteco-push.ts

server/__tests__/zkteco-push-parser.test.ts
```

نقاط التشغيل والراوتر والتصدير والواجهة لم تكن تسجل النظام القديم قبل الإزالة، لذلك لم تحتج إلى تعديل. لم تبق مراجع تنفيذية لهذه الملفات داخل مصادر التطبيق والخدمة والاختبارات المتبقية. المراجع التاريخية في الوثائق محفوظة.

## المكونات المحفوظة

- خدمة `biometric-service/` ومصادرها واختباراتها وإعداداتها.
- `server/biometric-integration.ts` و`server/biometric-final-events-importer.ts` و`server/biometric-web-bridge.ts`.
- ربط العامل عبر `biometricPersonCode` ورابط واجهة إدارة الخدمة المستقلة.
- مصادر الحضور وQR والمالية والرواتب وقواعد اليوم الإداري.
- تعريفات قاعدة البيانات وملفات الترحيل، بما فيها `drizzle/migrations/20260809_add_biometric_integration.sql` كسجل تاريخي لا يعاد تشغيله بسبب هذه الإزالة.

لم تنفذ أي أوامر تغيير مخطط قاعدة البيانات أو حذف بيانات أو إعادة حساب مالي. جداول النظام القديم وبياناتها إن وجدت تبقى كما هي. حذفها يحتاج تقييمًا منفصلًا للقاعدة الفعلية والاستخدامات الأخرى.

## نتائج التحقق

- بناء التطبيق `npm run build`: ناجح.
- اختبارات الخدمة المستقلة `npm test` داخل `biometric-service/`: نجح 194 من 194.
- اختبارات `biometric-integration` و`biometric-web-bridge` و`administrative-day-boundary`: نجح 12 من 12.
- فحص الأنواع قبل الإزالة: 609 تشخيصات خطأ TypeScript. بعد الإزالة: 579، دون تشخيصات خطأ جديدة مقارنة بالسابق. الفحص العام ما زال يفشل بسبب أخطاء سابقة؛ هذا ليس إعلانًا لسلامة الأنواع في كامل المشروع.
- مقارنة SHA-256 للملفات المحمية: لم تتغير مصادر النظام الجديد واختباراته وملفات الربط ونقاط التشغيل وتعريفات القاعدة وملفات الحزم المحددة في سجل المقارنة.
- لم تنفذ اختبارات تعتمد على بيانات إنتاج أو تسجيل حركات حقيقية. نجاح الاختبارات والبناء لا يعوض اختبار الإصدار في بيئة التجربة قبل النشر.

أعيد البناء واختبارات الربط خارج قيود العزل بعدما منعت القيود esbuild من قراءة مسار الإعدادات؛ نجح التشغيل اللاحق. سجلت النتائج في `.legacy-biometric-removal/`.

## الاستعادة

نظرًا لعدم وجود مستودع Git في النسخة المحلية، حفظت نسخة للملفات العشرة مع مساراتها الأصلية داخل:

```text

```

للتراجع، يفك الأرشيف أولًا إلى مجلد مؤقت، ثم تراجع محتويات مجلد `restore/` وتنسخ الملفات المطلوبة إلى مساراتها الأصلية داخل `finger/`، دون استبدال أي تغييرات أحدث. لا تستدعي الاستعادة ترحيل قاعدة بيانات. سجلات الفحوص وقائمة الملفات المحذوفة وبصمات الملفات المحمية محفوظة بجوار الأرشيف.

وثائق النظام القديم تحمل الآن تنبيهًا بأنها تاريخية وغير صالحة لتعليمات التشغيل الحالية.
