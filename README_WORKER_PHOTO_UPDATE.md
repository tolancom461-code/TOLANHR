# تحديث صور العمال — البرنامج الرئيسي فقط

التاريخ: 2026-09-05

## النطاق
هذا التحديث يخص البرنامج الرئيسي فقط، ولا يحتوي أي ملف من `biometric-service`، ولا يغيّر قاعدة البيانات أو الـ schema أو ملفات `.env`.

## ما تم تنفيذه
- استبدال حقل «رابط الصورة» في إضافة العامل برفع صورة فعلي.
- الصيغ المقبولة للمصدر: JPG/JPEG/PNG/WebP.
- الحد الأقصى للصورة الأصلية: 15 MB.
- المعالجة محليًا في المتصفح؛ الأصل لا يُرسل إلى السيرفر.
- التحويل النهائي إلى WebP.
- أقصى أبعاد نهائية: 800×800 مع الحفاظ على نسبة الصورة.
- جودة ابتدائية 82% مع خفض تدريجي عند الحاجة.
- الحجم المستهدف: حتى 1000 KB، والحد النهائي الصارم: 1300 KB.
- إزالة EXIF/GPS عمليًا عبر إعادة الرسم على Canvas قبل الرفع.
- رفع الملف النهائي إلى Object Storage الموجود أصلًا في المشروع.
- قاعدة البيانات تستمر باستخدام `workers.photo_url` الموجود، ولا يوجد Migration.
- لكل استبدال اسم ملف جديد لمنع مشكلة Cache للصورة القديمة.
- لا يوجد زر حذف للصورة؛ الاستبدال فقط.
- إذا فشل الرفع عند التعديل، تبقى الصورة القديمة كما هي.
- إذا فشل رفع صورة عامل جديد بعد إنشاء العامل، يبقى العامل محفوظًا ويمكن إضافة الصورة لاحقًا.
- الصورة تظهر مربعة وصغيرة في الاستعراض والتعديل وصفحة تفاصيل العامل.
- الضغط على الصورة يفتح معاينة كبيرة؛ الإغلاق بزر إغلاق، زر ×، الضغط خارج النافذة، أو Esc.
- الصور القديمة وروابطها الحالية تستمر في العمل كما هي حتى يتم استبدالها.

## الصلاحيات
رفع أو استبدال الصورة مسموح فقط لـ:
- `admin_affairs`
- `data_entry`
- `super_admin`
- المالك configured owner (مغطى صراحة أيضًا)

الأدوار الأخرى يمكنها رؤية الصورة عند قدرتها على عرض العامل، لكنها لا تستطيع رفعها أو استبدالها.

الحماية مطبقة في الواجهة والسيرفر معًا.

## التدقيق Audit
يسجل النظام في `audit_log` الحالي فقط:
- `ADD_WORKER_PHOTO`
- `REPLACE_WORKER_PHOTO`

ولا يخزن Base64 أو محتوى الصورة في سجل التدقيق.

## الأمان والتحقق على السيرفر
السيرفر يتحقق من:
- الصلاحية.
- أن الملف النهائي WebP فعليًا.
- أن الحجم النهائي لا يتجاوز 1300 KB.
- أن الأبعاد النهائية لا تتجاوز 800×800.

ولا يسمح بتغيير `photo_url` مباشرة عبر مسار تحديث العامل العام؛ تغيير الصورة يمر فقط بمسار الرفع المخصص.

## طريقة التركيب
فك محتويات ZIP فوق جذر المشروع الرئيسي مع استبدال الملفات المطابقة فقط.

لا يوجد SQL مطلوب.

## فحوص مقترحة بعد التركيب
```powershell
npm run check
npm test -- worker-photos
```

ثم شغّل البرنامج كالمعتاد واختبر:
1. إضافة عامل بصورة من دور مسموح.
2. فتح صورة العامل والتأكد من المعاينة الكبيرة والإغلاق.
3. تعديل العامل واستبدال الصورة.
4. الدخول بدور غير مسموح مثل `accountant` والتأكد أن الصورة للعرض فقط ولا يظهر رفع/استبدال.
5. التأكد من عدم وجود زر حذف للصورة.
