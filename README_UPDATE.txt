تحديث تكامل أجهزة البصمة — TolanWorkforce
التاريخ: 2026-08-09

هذه الحزمة مصممة لتُفك فوق جذر المشروع الحالي مع استبدال الملفات المتطابقة.
لا تحتوي على .env ولا على ملفات خطوط.

قبل التطبيق:
1) خذ نسخة احتياطية من المشروع وقاعدة البيانات.
2) احتفظ بملف .env الحالي كما هو.
3) راجع docs/APPLY_BIOMETRIC_UPDATE.md.

بعد التطبيق والتثبيت المعتاد للحزم:
- شغّل المشروع.
- سجل الدخول super_admin.
- افتح إعدادات النظام > أجهزة البصمة.
- أضف جهاز الاختبار Serial: MB2000-TEST-001 واربط PIN بعامل.
- اضغط «قبول الحركات من الآن».
- شغّل: npm run biometric:simulate

ملاحظة مهمة:
Handshake الحالي ملف توافق مبدئي لـ ZKTeco ADMS/PUSH. يجب تأكيده مع أول MB2000 حقيقي قبل اعتماد الإنتاج.
